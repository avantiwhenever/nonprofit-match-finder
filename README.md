# Nonprofit Match Finder

A free directory for finding real volunteer opportunities and paid nonprofit
jobs in the Seattle area — built for people looking for community,
structure, and social impact, with volunteering as a path into paid
mission-driven work too.

🔗 **Live:** [avantiwhenever.github.io/nonprofit-match-finder](https://avantiwhenever.github.io/nonprofit-match-finder/)

## What it is

Three tabs, searchable and filterable by cause, county, and distance:

- **Nonprofits** — 261 organizations across King & Snohomish County, WA,
  each with a real, hand-verified website
- **Volunteer Opportunities** — 69 real roles, hand-verified directly from
  each org's own site (schedule, commitment, requirements, sign-up link)
- **Paid Jobs** — 137 nonprofit jobs

No login, no ads, and nothing personal tracked. Every link goes straight to
the organization's own site — this is a discovery tool, not a booking
system.
